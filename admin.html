Admin — Sistema Guarda

Set the current week's content. This is the interim admin: there is no backend yet, so saving downloads an updated data/week.json — commit that file to the repo and GitHub Pages rebuilds in about a minute.

How to publish: download week.json below, then in the repo go to data/ → Add file → Upload files → replace week.json → Commit. Or git add data/week.json && git commit -m "Update week" && git push.
